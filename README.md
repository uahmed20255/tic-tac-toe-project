# Tic-Tac-Toe Game in Python
This is a console-based implementation of the classic Tic-Tac-Toe game. Players can enjoy a two-player game on a 3x3 grid where they alternate turns to place their mark ("X" or "O"). The game ends when one player gets three of their marks in a row, either horizontally, vertically, or diagonally, or when the board is full, resulting in a tie.

# Features:
- Two-Player Game: Play with a friend on the same device.
- Dynamic Game Board: The game board is updated after every move, providing a clear view of the current game state.
- Winning Conditions: The game checks for a winner after every move, evaluating rows, columns, and diagonals.
- Tie Condition: The game will declare a tie if all cells are filled without a winner.

# How to Play:
 - The game begins with an empty 3x3 grid.
- Players alternate turns. The first player uses "X", and the second player uses "O".
- Players can choose a position from 1 to 9, corresponding to the cells of the grid.
- The game will display the updated board after each turn.
- The game ends when one player wins or when all cells are filled (tie).

# Instructions:
Clone or download the repository.
Run the Python script in your terminal or command line.
Follow the on-screen prompts to play the game.
